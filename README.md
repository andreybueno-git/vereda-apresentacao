# vereda — apresentação do plano de negócio

Apresentação em uma página só (`index.html`), para o trabalho da faculdade:
o que é a vereda, a ideia personalizada que chega em casa, o site com a
peça 3D paramétrica ao vivo, missão · visão · valores, objetivos e metas,
localização.

Abra o `index.html` no navegador (ou o endereço do GitHub Pages), aperte
**F** para tela cheia e use as setas. Na capa, passe o ponteiro pela metade
direita: a luz revela a impressora. No slide do site, arraste os controles.

Tudo — imagens, vídeo e o motor de luz — está embutido no arquivo: funciona
sem internet. A fonte vem do Google Fonts e, se não carregar, cai numa
serifa parecida.

Marca: kit oficial da vereda (Fraunces + Work Sans; Verde Vereda, Barro,
Areia, Branco quente; o dourado só na peça acesa).
